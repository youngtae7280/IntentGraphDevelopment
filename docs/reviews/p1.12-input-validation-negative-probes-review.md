## Scope

P1.12 adds a repeatable negative-probe harness for the CF0 P1.11 invalid-integer overlay-only contract delta. The harness starts from committed good P1.11 inputs, mutates temporary copies, runs `tools/verify_code_first_delta.py`, and passes only when every bad input fails for the expected reason.

This is a hardening slice only. It does not add another behavior unit, change CF0 source behavior, build a generic negative-probe framework, alter B0 generated-code behavior, or add dependencies.
