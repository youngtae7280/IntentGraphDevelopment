## Scope

P3.0 is the first Phase C implementation slice. It maps B1 Intent Units to existing B1 code facts without editing source code or generating mappings automatically.

This slice does not perform code edits, AI mapping generation, natural-language request interpretation, broad planning, workbench UI, broad extraction, or productization.

## Intent Units

P3.0 maps these B1 units:

- `unit.behavior.create-todo`
- `unit.behavior.list-todos`
- `unit.behavior.complete-todo`
- `unit.contract.title-required`
- `unit.route.get-todos`
- `unit.route.post-todos`
- `unit.verification.todo-service-tests`

Each unit uses `codeRefs`, `codeFactRefs`, and `mappingObligations` pointing to B1 facts.

## What P3.0 Proves

P3.0 proves:

- B1 code facts can support a static Intent Unit overlay.
- Intent Units can point to route, function, call, type, and test facts without copying source text.
- Mapping obligations can require verification, evidence, and authority references.
- Bad mappings fail deterministically.

## What P3.0 Does Not Prove

P3.0 does not prove:

- natural-language request interpretation
- automatic mapping generation
- ambiguity resolution workflow
- code edit planning
- stale mapping repair
- UI/workbench usability
- real-project adoption
