## Phase C Entry Criteria

Phase C may open only as a bounded B1 mapping slice.

The first Phase C slice must:

- define B1 Intent Unit mapping schema
- create a small B1 overlay fixture
- map accepted behavior/contract units to existing B1 code facts
- require `codeRefs`, `codeFactRefs`, and `mappingObligations`
- verify that all mapping refs resolve against B1 code facts
- mark ambiguity explicitly when mapping is not unique
- keep AI-generated mapping candidates proposal-only

The first Phase C slice must not:

- perform code edits
- generate AI mapping automatically
- build a broad planner
- build a workbench UI
- broaden extraction
- claim natural language intent recovery
- grant AI authority

## Recommended P3.0 Slice

```text
P3.0 B1 Intent Unit Mapping Schema and Static Overlay Fixture
```

P3.0 should define a small overlay with Intent Units such as:

- `unit.behavior.create-todo`
- `unit.behavior.list-todos`
- `unit.contract.title-required`
- `unit.route.get-todos`
- `unit.route.post-todos`

Each unit should map to existing B1 facts through `codeRefs`, `codeFactRefs`, and `mappingObligations`.

P3.0 should also add a verifier and negative probes for:

- missing code fact ref
- wrong expected fact kind
- missing mapping obligation
- missing evidence or authority reference
- source text equality claim
- ambiguous mapping accepted as resolved
