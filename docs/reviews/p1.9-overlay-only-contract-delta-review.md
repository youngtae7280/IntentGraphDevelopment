## P2 Decisions

- `P1.9-P2-001`: the extractor records simple stderr output facts but does not infer full branch semantics. Decision: defer richer control-flow facts until another contract requires them.
- `P1.9-P2-002`: usage and invalid-integer stderr facts are extracted but not modeled as accepted behavior units. Decision: defer to a future overlay-only contract slice if Coordinator selects it.
- `P1.9-P2-003`: P1.9 initially had no dedicated negative harness. Decision: resolved by P1.10, which added repeatable overlay-only contract delta negative probes.

## Recommendation

Continue. A useful next slice is either another overlay-only contract for input validation, or a small negative harness proving overlay-only deltas fail when source changes unexpectedly or delta records are missing.
