## Phase F Entry Criteria

Phase F may open only as a bounded B1 static workbench projection slice.

The first Phase F slice must:

- define a workbench projection JSON shape
- consume B1 code facts, overlay, proposal, proposal validation, and consistency reports
- expose request/proposal, impacted files, Intent Units, code facts, planned deltas, tests, evidence, authority, and verifier status
- create a static HTML preview from the projection
- support selectable sections or nodes without hiding verifier failures
- include screenshot or rendered HTML existence validation
- remain local/static and non-productized

The first Phase F slice must not:

- mutate source
- apply the proposal
- accept the proposal
- build a production app
- claim visualization verifies correctness
- add external dependencies without a decision record
- productize editor/GitHub/team workflows
