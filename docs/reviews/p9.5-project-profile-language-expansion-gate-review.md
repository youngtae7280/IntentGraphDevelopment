# P9.5 Project Profile Authoring and Language Expansion Gate Review

Work item: P9.5 Project Profile Authoring and Language Expansion Gate - Plan Only

Date: 2026-07-13

Reviewer: IntentGraphDevelopment Roadmap Orchestrator

Decision: select a WindowsUtility C# syntax-only, read-only feasibility probe for P9.6. Do not yet introduce a reusable C# profile or a packaged dependency.

## Evidence Considered

WindowsUtility is clean and aligned at `ac5b2204442cde751f625a9979a4fdb437d468a8`. Its `src` tree contains 17 C# projects and 206 source files after excluding generated `bin`/`obj` content. The project has App, Core, Services, Native, Modules, Diagnostics, and Shell layers, making it a meaningful profile expansion beyond the B1 TypeScript fixture.

The local .NET SDK exposes Roslyn C# assemblies. That establishes feasibility for a disposable parser probe, not a portable product dependency or a license/distribution decision.

## Chosen Boundary

P9.6 may parse only C# syntax in a sandbox copy or read-only source scope. It must not load an MSBuild workspace, restore packages, build the solution, execute analyzers or generators, bind assemblies, launch the app, or touch hardware.

The initial graph must preserve source provenance and confidence. Syntax-only invocations may be extracted, but their targets are not semantic proof and must not be presented as resolved call edges.

## Rejected Paths

- regular-expression C# extraction: not sufficient for nested types, methods, properties, constructors, and syntax provenance
- immediate Roslyn packaging: host SDK availability is not a product dependency decision
- MSBuild/solution semantic loading: too much execution and environmental authority for the first probe
- WindowsUtility source edit/build/run: unrelated to source fact extraction and not needed

## Non-Goals Preserved

- no WindowsUtility source mutation, build, launch, hardware action, commit, or push
- no arbitrary C# project support
- no network, provider, credential, hook, package, signing, release, or productization authority

## Recommendation

Continue to `P9.6 WindowsUtility C# Syntax-Only Feasibility Probe`. The probe must use a sandboxed, read-only copy and prove target source state unchanged before and after extraction.
