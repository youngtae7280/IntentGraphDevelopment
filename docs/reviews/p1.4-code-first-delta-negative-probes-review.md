Date: 2026-07-09
Reviewer: IntentGraphDevelopment Roadmap Orchestrator

Decision: continue

## Scope

P1.4 adds a repeatable negative-probe harness for the CF0 P1.3 code-first maintenance delta verifier. The harness starts from the committed good CF0 delta inputs, creates mutated copies in a temporary directory, runs `tools/verify_code_first_delta.py`, and passes only when every negative probe fails with the expected error.

After P1.7, this harness is explicitly historical: it verifies the P1.3 additive after-state where the implementation function is still `mul`. It must not use the current P1.7 `multiply` facts or overlay as its baseline.

This is a harness slice only. It does not add a second maintenance delta, broaden extraction, add AI runtime behavior, or change the workbench/UI.

## P2 Decisions

- `P1.4-P2-001`: negative fixtures are generated in temporary directories rather than committed as bad JSON examples. Decision: defer committed bad fixtures because the harness report is deterministic and avoids maintaining intentionally invalid source artifacts.
- `P1.4-P2-002`: the harness is CF0-specific. Decision: defer a generic negative-probe framework until another benchmark or delta shape exists.
