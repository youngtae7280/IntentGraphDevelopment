## Proposal Boundary

A valid non-applied proposal must include:

- accepted mapping id
- target baseline head
- intended task class
- proposed code delta, explicitly empty unless a later slice authorizes code proposals
- evidence requirements
- authority requirements
- rollback/stop conditions
- deterministic verification plan
- `applyAuthorized:false`
- `targetWritesAuthorized:false`
- `aiAuthorityPromoted:false`
- `productizationAuthorized:false`

## Blocking Conditions

Block the proposal if it:

- targets a mapping that is not accepted.
- uses stale source refs.
- omits evidence requirements.
- omits authority requirements.
- includes source edits without explicit source-edit proposal authorization.
- claims apply authority.
- claims AI authority.
- claims productization readiness.
