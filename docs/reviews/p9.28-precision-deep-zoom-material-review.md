# P9.28 Precision Deep Zoom and Graph Material Review

## Decision

P9.28 passes its bounded visual and interaction slice.

The Workbench now reaches the requested 100x inspection level without scaling selected
relations, endpoint nodes, borders, or state highlights into oversized shapes. The
visual treatment is darker, less saturated, and materially deeper while retaining the
same unified graph and deterministic layout.

## Acceptance Evidence

- static P9.28 emission and validation pass;
- all 21 loopback server probes pass;
- the live browser reaches 100x through one explicit toolbar command;
- a real extracted code relation measures 0.420 rendered pixels at 100x;
- its endpoint nodes measure 15.2 rendered pixels with 0.2-pixel borders;
- the same precision boundary keeps a high-level project-to-capsule relation from
  producing an oversized underlay;
- the direct 100x transition settles in approximately 1.5 seconds in browser QA; and
- the code-topology lens, inspector, work history, graph delta, and code diff remain
  visible and functional.

## Findings Resolved During Review

1. Coarse deep-zoom bands left old node sizes visible during rapid zoom. Precision
   bands now scale node, border, label, and relation values immediately.
2. State-specific borders overrode base compensation. State, selection, search, and
   delta selectors now receive precision widths too.
3. Label-aware underlays could cover the canvas at high zoom. Precision zoom disables
   node underlays and keeps the rim.
4. Repeated full-graph restyling exceeded the interaction budget. Precision updates
   are restricted to the current viewport neighborhood and refresh after pan settle.
5. A 1000x experimental ceiling exposed renderer behavior outside the requested
   product boundary. The supported maximum is now exactly 100x.
6. The previous material read as saturated plastic. P9.28 replaces it with one shared
   desaturated spectral-obsidian texture and cheaper code-fact glyphs.

## Preserved Boundaries

- graph structure changed: false

- target repository mutation: false

- automatic code application: false
- approval automation: false
- network/provider/credential access: false

This slice improves inspection quality only. The next normal-workflow gap is still
