## Boundary

The visual comparison used Graphify's MIT-licensed renderer implementation as a
reference for presentation mechanics. IntentGraph graph facts and relation semantics
are unchanged; deterministic presentation spacing was revised. The committed screenshot
captures the actual `512x` selected-edge state. Deterministic checks guard concrete
regressions such as missing colors, oversized labels, a second renderer, broken relation
pixels, or an invalid deep-zoom state. Virtual-time interaction values are diagnostic;
only the complete capture has a wall-clock performance gate.
