# P9.8 Experimental Host-SDK C# Profile Availability Preflight Review

Date: 2026-07-13

Decision: pass the local availability preflight. Keep the profile experimental, host-specific, non-portable, and not product-ready.

## Evidence

- The profile uses exact role/status/scope and keeps source extraction, target access, package operations, network, and productization authority false.
- The local preflight selected SDK `9.0.100` and found the required Roslyn assemblies with recorded byte lengths and SHA-256 digests.
- The report contains no absolute host path and no target source path.
- Two positive preflight runs were byte-identical.
- Nine negative cases fail deterministically, including a fake local SDK with the required assembly genuinely absent.

## Boundary Review

This is an environmental diagnostic, not a dependency resolver. It does not prove a supported SDK matrix, clean installation, offline operation, package lock, security-update policy, or source extraction workflow.

## Recommendation

Open `P9.9 Experimental C# Local Workspace Integration Boundary Plan - Plan Only`. The plan must determine whether a source snapshot is copied before extraction, which workspace artifact contracts apply, and how fact-only C# evidence remains separate from mapped semantic intent.
