Decision: pass; continue to a bounded ambiguity mapping candidate slice.

## Scope

P3.1 proves that B1 static mappings fail deterministically when a mapped code fact disappears from the supplied code facts.

This slice does not edit source code, repair mappings automatically, generate AI mappings, start code planning, build UI/workbench, broaden extraction, or productize the workflow.

## Probe

The stale probe removes:

```text
fact.function.addtodo
```

from a copied B1 code fact report.

The normal B1 overlay is then verified against the stale facts. The verifier is expected to fail because these mappings refer to the missing fact:

- `unit.behavior.create-todo`
- `unit.route.post-todos`

## What P3.1 Proves

P3.1 proves:

- accepted mappings are not silently kept valid when a mapped fact disappears
- stale mapping failure is deterministic
- failure messages name the missing mapped fact
- stale probe artifacts do not mutate source code

## What P3.1 Does Not Prove

P3.1 does not prove:

- automatic mapping repair
- ambiguity resolution
- natural-language remapping
