# P9.23 Relation-Aware C# Graph Review

Date: 2026-07-13

## Decision

P9.23 passes the read-only relation-overlay and relation-aware rendering boundary.

## Evidence

- the local Roslyn sidecar recorded `5,623` deterministic local-symbol relations for
  the WindowsUtility snapshot; `915` cross module boundaries are represented
- the source snapshot still remains syntax-only; the sidecar is a separate,
  validated overlay and records `2,914` compilation diagnostics rather than claiming
  a successful target build
- the WindowsUtility full graph now emits `8,189` nodes and `13,664` relations with
  `calls`, `references`, `constructs`, `inherits`, and `implements` available as
  relation filters
- the local server smoke passes 20 probes after recording a synthetic validated
  relation overlay into a temporary project workspace
- repeatable relation-overlay negative probes reject target-build claims, unknown
  code-fact endpoints, source text persistence, source-build capability, and source
  digest mismatch while preserving the project state byte-for-byte
- static workbench emission and validation pass with the relation-aware layout
  contract and five-band zoom styling
- browser inspection confirms the relation filter, the sidecar counters, the full
  graph render, and the local-source authority boundary

## Non-goals

- no target source mutation, build, restore, launch, package action, remote call,
  credential access, or code application
- no claim that local-symbol resolution is a complete project-wide semantic model
- no automatic mapping, proposal application, verification execution, evidence
  collection, approval, or graph-delta application
