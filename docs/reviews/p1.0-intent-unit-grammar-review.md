## Result

B0 now has explicit accepted Intent Units:

- `unit.product.calculator`
- `unit.behavior.add`
- `unit.behavior.sub`

The product unit refines into the add and subtract behavior units through `unitEdges` with `kind: "refines"`.

Each unit declares:

- contract
- internal graph node and edge membership
- projection expectations
- reconstruction expectations
- verification expectations
- evidence linkage
- authority linkage
- history linkage
- admission fields distinguishing accepted units from raw utterances or hypotheses

## Round-Trip Status

The P1.0 target is:

```text
G_unit -> Native(G_unit) -> (C, mu_unit) -> Retrofit(C, mu_unit) -> G_unit' -> Verify(G_unit, G_unit')
```

The implemented B0 loop passes with metadata-backed equality. The verifier now reports Intent Unit preservation in addition to node/edge equality and evidence/authority/history semantics.

## Hidden Snapshot Status

`hiddenState.sourceGraphSnapshot` remains necessary for exact B0 reconstruction. P1.0 does not claim to remove it.

P1.0 adds `unitMap` and `hiddenState.snapshotDependence` metadata so the dependency is measured:

- source graph snapshot still used: true
- unit identities and internal memberships are represented separately in metadata
- code-only reconstruction remains lossy

Phase 1 should reduce the full-snapshot dependency by moving evidence, authority, history, and unit reconstruction into typed preservation metadata before broader benchmarks.

## Boundary Status

- code-only reconstruction remains lossy
- generated code is not treated as proof
- AI proposal output remains proposal-only
- workbench projection remains report state, not authority
- no larger benchmark, broad workbench, arbitrary code extractor, or AI runtime was introduced
