## State Boundary

The index records:

- `cf0.state.p1.3.before-add-mul`
- `cf0.state.p1.3.after-add-mul`
- `cf0.state.p1.7.current-refactor-multiply`

The historical states point to generated historical source/facts/overlay artifacts. The current state points to the mutable current CF0 source, current extracted facts, and current overlay.

The P1.3 after-state contains:

- `fact.function.mul`
- `fact.function.mul.return.left_times_right`
- `fact.function.main.calls.mul`

The P1.7 current state contains:

- `fact.function.multiply`
- `fact.function.multiply.return.left_times_right`
- `fact.function.main.calls.multiply`

The current state does not use the old `mul` implementation facts as current mappings.

P1.9 updates this index after the overlay-only unsupported-operation contract delta. The P1.7 refactor state becomes historical, and `cf0.state.p1.9.current-overlay-unsupported-operation` becomes the single current state.

## P2 Decisions

- `P1.8-P2-001`: the index is CF0-specific. Decision: defer a general history engine until at least one more benchmark or transition shape proves the abstraction is worth extracting.
- `P1.8-P2-002`: JSON artifact digests use canonical JSON while source digests use file bytes. Decision: accept and record digest mode per artifact because it matches existing verifier conventions.

## Recommendation

Continue. A good next slice is a Coordinator-selected semantic overlay probe, such as another code-first delta shape, now that historical/current artifact boundaries are indexed and machine-checkable.
