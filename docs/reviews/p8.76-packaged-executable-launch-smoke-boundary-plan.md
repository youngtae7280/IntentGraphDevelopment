## Scope

P8.76 defines the future boundary for launching the packaged WindowsUtility executable from a sandbox. It does not launch anything.

Packaged executable launch is stronger than package extraction inventory verification. It requires both:

- sandboxed extraction inventory verification of the existing package
- explicit launch-smoke authorization

The launch authorization response would be:

```text
accept sandboxed packaged executable launch smoke
```

That response is not recorded.

## Future Boundary

Future launch smoke may only happen after authorization and only from a sandbox extraction directory.

Future launch smoke may record:

- startup process health
- stdout/stderr/log files produced inside the sandbox
- UI screenshot only if a separate screenshot authorization exists
- generated smoke evidence

Future launch smoke must not:

- install globally
- edit WindowsUtility source
- commit or push WindowsUtility
- sign artifacts
- read credentials
- call provider APIs
- create release tags
- publish releases
- claim productization readiness
