## Scope

P1.7 adds a tiny code-first refactor delta for CF0. The CLI behavior remains stable while the implementation function for the accepted multiply behavior changes from `mul` to `multiply`.

This proves a non-additive maintenance shape: `unit.behavior.mul` remains the stable Intent Unit, but code facts and overlay mappings move underneath it. The phase does not add a new behavior unit, require source text equality, use a hidden generated-code snapshot, or broaden the benchmark.

## Mapping Migration

Before P1.7, `unit.behavior.mul` mapped to:

- `fact.function.mul`
- `fact.function.mul.return.left_times_right`
- `fact.function.main.calls.mul`

After P1.7, `unit.behavior.mul` maps to:

- `fact.function.multiply`
- `fact.function.multiply.return.left_times_right`

The product unit's main-call mapping now references:

- `fact.function.main.calls.multiply`

The refactor report records the old `mul` implementation facts in `removedCodeFactIds`, not as current mappings.
