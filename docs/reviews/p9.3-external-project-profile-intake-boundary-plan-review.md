# P9.3 External Project Profile Intake and Workspace Import Boundary Plan Review

Work item: P9.3 External Project Profile Intake and Workspace Import Boundary Plan

Date: 2026-07-13

Reviewer: IntentGraphDevelopment Roadmap Orchestrator

Decision: open only a B1-equivalent external-source snapshot/import proof. Do not treat external intake as arbitrary-project or multi-language support.

## Why This Boundary Exists

P9.2 made a bundled B1 workspace portable. It still copied source from inside the IntentGraphDevelopment repository. The next necessary proof is that the tool can read an external source root, leave it unchanged, and create the same declared local-review workspace without leaking the external absolute path into persistent graph artifacts.

WindowsUtility P7 evidence supplies the relevant safety precedent: source state and digests are observed before and after read-only analysis, while target mutation remains false. It does not supply a symbol-level C# extractor or authorize WindowsUtility intake through the B1 profile.

## P9.4 Constraints

P9.4 accepts an external B1-equivalent TypeScript source tree only. It must verify the exact bounded source file set and digests before copying to a new workspace. The workspace then runs the existing P9.2 profile; no external source is analyzed in place or modified.

The intake receipt must contain stable evidence, not the external absolute path. It must show before/after source-tree digest equality, copied files, profile ID, logical source root, and all false authority flags.

## Rejected Alternatives

- importing arbitrary TypeScript now: the current extractor and overlay/proposal are B1-bounded
- importing WindowsUtility now: P7 inventory is file/project-level and there is no C# symbol fact profile
- analyzing in place: would blur workspace ownership and target-write safety
- accepting profiles supplied with executable instructions: would introduce undeclared authority

## Non-Goals Preserved

- no external source mutation or Git operation
- no code application or proposal acceptance
- no network, provider, credential, hook, signing, package, or release action
- no productization claim

## Recommendation

Continue to `P9.4 B1-Equivalent External Source Snapshot Import`. Its acceptance must require a disposable external source copy, before/after digest proof, generated intake receipt, workspace review pass, and repeatable negative probes.
