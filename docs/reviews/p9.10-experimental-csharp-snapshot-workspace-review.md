# P9.10 Experimental C# Snapshot Workspace and Fact Extraction Probe Review

Date: 2026-07-13

Decision: pass the experimental fact-only snapshot workspace probe. Do not add C# intent mapping, proposal, or product support.

## Evidence

- `init-experimental-csharp` accepts only the declared P9.8 profile and requires successful local preflight.
- The C# intake copies only non-symlink `.cs` files outside `bin` and `obj` into a new workspace.
- Receipt, manifest, facts, extraction report, and validation report use a logical source root and no external absolute path.
- Fixed fixture workspaces are byte-identical across fresh directories.
- The real WindowsUtility snapshot workspace validates 206 files, 8,137 facts, and 7,931 relations.
- Ten negative cases fail deterministically, including a source mutation after copy and before post-intake digest verification.

## Source-State Interpretation

The external source tree was modified independently between two reproduction attempts. This did not invalidate either workspace: their source receipts bind fact evidence to their own captured digest. P9.10 therefore intentionally validates snapshot coherence, not a claim that an arbitrary live worktree stays unchanged across separate user sessions.

## Preserved Boundary

- no target source write, target build/restore/launch, external package restore, package dependency, network, provider, credential, hook, code application, release, or productization authority
- the disposable parser uses only a local build-assets restore with package sources cleared; this is recorded separately from external/target package operations
- no semantic resolution or resolved call graph
- no Intent Unit mapping, proposal, acceptance, consistency verifier, or product workbench for the C# workspace

## Recommendation

Open `P9.11 Experimental C# Fact Workspace Scope Review - Plan Only`. The review must decide whether mapping coverage should remain deferred, what representative code-fact quality checks remain missing, and whether a limited fact workspace can enter a generic workbench without misrepresenting semantic coverage.
