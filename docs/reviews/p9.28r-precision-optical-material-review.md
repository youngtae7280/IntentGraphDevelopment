# P9.28.R Precision Optical Material Review

## Decision

P9.28.R passes its bounded rendering correction.

The Workbench now exposes logical `100x` inspection through a renderer-safe virtual
precision band, tapers selected relation emphasis at deep zoom, and replaces the
remaining colored-plastic landmark bodies with dark optical cores and restrained
spectral rims.

## Acceptance Evidence

- static and live HTML inline JavaScript parse successfully;
- the final loopback server smoke passes all 21 probes;
- the broader affected regression set passes 80 probes across nine reports;
- browser QA reaches logical `100x` at renderer zoom `24.000`;
- a selected real relation measures `0.240` rendered pixels at logical `100x`;
- its structural endpoints measure approximately `15.216` and `18.864` rendered
  pixels;
- browser QA confirms Fit returns to `x0.22` after deep inspection;

- the inspector, work history, graph delta, and code-diff surfaces remain present.

## Correction Rationale

1. Literal Cytoscape `100x` magnified the renderer's fixed one-model-unit node
   bounds expansion into a large per-node screen-space cost. P9.28.R maps the
   logical `18x..100x` band to renderer `18x..24x`.
2. A selected relation that stayed visually constant still felt too heavy at maximum
   zoom. The deep band now tapers selected relations to `0.24` pixels and neighboring
   highlights to `0.14` pixels.
3. Native gradient and bitmap material attempts caused high-zoom canvas defects.
   The accepted material uses only stable solid fill, border, outline, and bounded
   underlay primitives.
4. Colored landmark interiors still looked like plastic pieces. Semantic and
   structural landmarks now use an obsidian core with category color confined to
   the optical rim.
5. Tiny non-elliptical paths could expand into a full-canvas field. Precision mode
   uses ellipse geometry while preserving category-specific shapes at normal zoom.
