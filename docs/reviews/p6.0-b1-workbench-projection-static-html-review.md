## Scope

P6.0 emits a deterministic B1 workbench projection JSON and a static local HTML preview for the non-applied proposal workflow.

This slice does not mutate source, apply or accept proposals, claim visualization verifies correctness, build a production app, add editor/GitHub integration, or productize the workflow.

## Projection Coverage

The projection exposes:

- proposal summary and non-applied status
- workflow timeline
- impacted source files
- existing and proposed Intent Units
- impacted code facts
- planned source deltas
- planned mapping updates
- required tests
- required evidence
- required authority
- proposal validation status
- proposal consistency status
- selectable records for details inspection

## Preview Boundary

The HTML preview is static and local. It contains section controls and selectable records, but it is not a verifier and does not grant authority.

Claim scope:

- `staticPreviewOnly:true`
- `visualizationVerifiesCorrectness:false`
- `sourceMutated:false`
- `patchApplied:false`
- `proposalAccepted:false`
- `productized:false`
