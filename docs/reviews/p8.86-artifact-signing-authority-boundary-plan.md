## Scope

P8.86 defines the future boundary for signing a verified WindowsUtility package or installer artifact. It does not sign artifacts.

Signing is stronger than packaging or installer planning. It requires:

- verified package or installer artifact
- deterministic signing policy
- key/certificate authority boundary
- explicit artifact signing authorization

The signing authorization response would be:

```text
accept sandboxed artifact signing
```

That response is not recorded.

## Future Boundary

Future signing may only happen after all preconditions pass and only inside a sandbox/staging directory.

Future signing may record:

- signed artifact under `generated/`
- signature metadata
- certificate fingerprint
- artifact hash
- signer policy version

Future signing must not:

- edit WindowsUtility source
- commit or push WindowsUtility
- create an installer unless separately authorized
- install globally
- call provider APIs
- create release tags
- publish releases
- claim productization readiness
