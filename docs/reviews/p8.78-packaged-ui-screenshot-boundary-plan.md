## Scope

P8.78 defines the future boundary for capturing packaged UI screenshot evidence. It does not launch the packaged executable and does not capture screenshots.

Packaged UI screenshot capture is stronger than launch smoke. It requires:

- sandboxed extraction inventory verification
- packaged executable launch smoke authorization and pass result
- explicit screenshot authorization

The screenshot authorization response would be:

```text
accept sandboxed packaged UI screenshot capture
```

That response is not recorded.

## Future Boundary

Future screenshot capture may only happen after all preconditions pass and only from a sandbox extraction directory.

Future screenshot capture may record:

- screenshot evidence under `generated/`
- screenshot metadata
- process and window observation facts

Future screenshot capture must not:

- install globally
- edit WindowsUtility source
- commit or push WindowsUtility
- sign artifacts
- read credentials
- call provider APIs
- create release tags
- publish releases
- claim productization readiness
