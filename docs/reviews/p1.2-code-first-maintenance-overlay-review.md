# P1.2 Code-First Maintenance Overlay Review

Work item: P1.2 Tiny Code-First Maintenance Overlay Probe
Date: 2026-07-09
Reviewer: IntentGraphDevelopment Roadmap Orchestrator

Decision: continue

## Scope

P1.2 adds the first code-first maintenance overlay probe. Unlike B0, CF0 starts from hand-written source code and verifies overlay mappings against deterministic code facts.

CF0 proves this tiny loop:

```text
C -> Extract(C) = X
I + X -> M
Verify(I, C, X, M, E, A, H) -> pass/fail
```

It does not require source text equality and does not use a hidden generated-code snapshot.

## Review Findings

### P0/P1

No unresolved P0 or P1 issues remain.

### P2

- `P1.2-P2-001`: CF0 uses a tiny custom Python AST extractor instead of an external code intelligence system. Decision: defer because broad extraction and external integration are non-goals for this phase.
- `P1.2-P2-002`: behavior verification is limited to add/sub smoke checks. Decision: defer because CF0 is the smallest code-first proof, not a full test framework.
- `P1.2-P2-003`: CF0 does not yet model a code change `C -> C'`. Decision: defer to a future maintenance-delta slice.

## Residual Risk

CF0 proves that the overlay architecture can work over hand-written source for a tiny calculator. It does not prove multi-file maintenance, edits, semantic diffing, external extraction, policy integration, or behavior equivalence beyond smoke tests.

## Recommendation

Continue. The next slice should introduce a tiny code-first maintenance delta or reduce generated-code snapshot dependence, but it should not broaden to a larger benchmark yet.
