## Negative Probes

The harness must fail for:

- stale source digest
- missing source ref
- mapping draft marked accepted
- target write authority marked true
- target baseline marked accepted

The committed negative-probe report has `result: pass`, `probeCount: 5`, and every probe has `expectedFailureObserved: true`.
