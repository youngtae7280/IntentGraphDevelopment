## Benchmarks

### Performance

- inventory completes within a documented time budget
- file count and selected source file count are recorded
- generated IntentGraph-side reports are deterministic across reruns
- target repository remains unmodified

### Workflow

- output identifies candidate Intent Units and code facts
- output identifies unresolved mappings and ambiguity
- output lists evidence and authority gaps
- output is inspectable in JSON/Markdown before any UI expansion

### Quality Comparison

Compare against ordinary AI coding by asking:

- would an AI worker know which files are in scope?
- would it know which evidence is required?
- would it know where authority is missing?
- would it avoid changing source before review?
- would it expose ambiguity instead of hiding it?

## Stop Conditions

Stop before adoption expands if:

- WindowsUtility is not clean enough for adoption work
- read-only inventory cannot avoid writing into the target repo
- output is mostly noise and does not help scope review
- inventory takes too long for a small bounded slice
- reports cannot explain evidence/authority gaps
