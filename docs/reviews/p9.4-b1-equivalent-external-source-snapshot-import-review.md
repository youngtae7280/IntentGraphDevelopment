# P9.4 B1-Equivalent External Source Snapshot Import Review

Work item: P9.4 B1-Equivalent External Source Snapshot Import

Date: 2026-07-13

Reviewer: IntentGraphDevelopment Roadmap Orchestrator

Decision: an external B1-equivalent TypeScript source tree can be copied into a new local-review workspace without mutating the external tree or persisting its absolute path.

## Implementation

`python tools/intentgraph.py import-b1-equivalent --workspace <new-workspace> --source-root <external-source>` validates the external source tree before creating the workspace. It accepts only the exact B1 TypeScript file set and file digests, copies that tree into the workspace, rechecks the external tree, writes a path-free intake receipt, and validates the new P9.2 workspace profile.

The imported workspace can then run the existing local `review` workflow and emit its workbench.

## Evidence

- a disposable external B1 source copy imported successfully
- its source tree digest was identical before and after import/review
- the copied workspace source evidence matched the external tree
- the intake receipt retained profile and digest evidence without the external absolute path
- the imported workspace review passed and produced `workbench.html`
- seven repeatable negative probes passed for missing/file roots, unsupported files, non-equivalent content, workspace overlap, pre-existing workspace, and tampered intake receipt

## Boundary

This is not arbitrary project support. It does not import WindowsUtility, C#, or a user-authored TypeScript project. It does not retain external absolute paths, mutate a target repository, apply code, invoke a provider, access credentials, install hooks, package a product, or publish a release.

## Recommendation

Continue to `P9.5 Project Profile Authoring and Language Expansion Gate - Plan Only`. The next decision must identify a safe way to add a second source shape without turning declarative profiles into executable authority.
