## Scope

P2.0 is the first Phase B implementation slice. It creates a tiny multi-file TypeScript REST-style fixture and proves a deterministic B1-bounded code fact contract.

This slice does not implement a broad extractor, workbench, AI planning, Intent mapping, product runtime, TypeScript compiler integration, or real-project adoption.

## What P2.0 Proves

P2.0 proves that IntentGraph can represent a small multi-file, non-Python codebase as deterministic code facts without copying source text into the graph.

Validated facts include:

- file facts
- module facts
- function facts
- type facts
- route facts
- test facts

- call facts

Validated relations include:

- contains
- imports
- references
- calls

- tests
