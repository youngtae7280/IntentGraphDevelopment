## Scope

P8.90 defines the future boundary for release tag creation, release artifact publishing, and release evidence records. It does not create a tag and does not publish a release.

Release is stronger than package, installer, and signing planning. It requires:

- product candidate acceptance
- verified release artifact
- signing status record
- release notes and rollback guidance
- explicit release authority
- provider/credential authority before any provider API call or token access

The release authorization response would be:

```text
accept sandboxed release authority
```

That response is not recorded.

## Future Boundary

Future release planning may record:

- release candidate manifest under `generated/`
- release notes
- artifact hashes
- release tag proposal
- provider/credential authority requirements

Future release work must not:

- edit WindowsUtility source
- install globally
- sign artifacts unless separately authorized
- access credentials without provider/credential authority
- call provider APIs without provider/credential authority
- create release tags without release authority
- publish releases without release authority
- claim productization readiness without final productization authority
