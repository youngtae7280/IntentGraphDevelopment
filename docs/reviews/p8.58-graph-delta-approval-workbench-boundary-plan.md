## Scope

P8.58 turns the P8.57 coordinator requirement into an implementable boundary.

This is still a plan/report slice. It does not implement the graph workbench, mutate WindowsUtility, apply proposals, extract or run the package, publish releases, or claim productization readiness.

## Boundary

The approval-stage workbench must be an interactive graph surface, not a card/table dashboard.

It must show:

- graph nodes and edges.
- graph delta state.
- selectable nodes and edges.
- selected element details.
- selected delta-step highlights.
- code diffs for code nodes and code-affecting deltas.
- graph before/after diffs for changed existing nodes.
- graph before/after diffs for changed existing edges.
- evidence and authority records linked to selected graph elements.
- blockers when required diff data is missing.

## Build / Borrow / Integrate

Preferred graph visualization layer:

```text
Cytoscape.js
```

Reason: Cytoscape.js is strong for graph exploration, selection, data-driven styling, layouts, pan/zoom, and static local HTML packaging.

Constraints:

- bundle locally.
- no CDN.
- no network dependency.
- no UI mutation authority.
- no graph-coordinate authority.

## Validation Standard

The first implementation must prove:

- every edge endpoint exists.
- every visible node/edge has an inspector payload.
- changed nodes have graph-node diff refs.
- changed edges have graph-edge diff refs.
- code-affecting nodes/delta steps have code diff refs.
- missing required diff refs become blockers.
- delta steps reference only existing nodes, edges, and diff records.
- HTML contains graph canvas, node inspector, edge inspector, delta list, code diff panel, graph diff panel, and evidence/authority panel.
- negative probes reject broken endpoints, missing inspector payloads, missing diffs, network scripts, mutation controls, and false authority flags.

## Graphify-Grade Task Bar

The workbench should support these review tasks:

- search for a node and inspect its incoming/outgoing edges.
- select an edge and inspect source/target/provenance.
- filter graph by delta state.
- select a delta step and see affected nodes/edges highlighted.
- select a changed code node and see source diff.
- select a changed existing node and see graph before/after diff.
- select a changed existing edge and see graph before/after diff.
- verify linked evidence and authority for a selected graph element.
- confirm productization and execution blockers are visible.
