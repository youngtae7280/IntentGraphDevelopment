## Consolidation Decision

Consolidation was performed in `tools/cf0_probe_support.py` for low-risk repeated mechanics:

- overlay-contract report assembly
- positive baseline rerun wiring
- probe execution loop
- common source/snapshot boundary fields
- optional historical input report block

The individual harness scripts still own:

- phase-specific path constants
- phase-specific mutation functions
- phase-specific probe ids and expected error strings
- semantic meaning of `baselineScope`

This keeps the helper CF0-specific and prevents it from becoming a vague framework with hidden special cases.
