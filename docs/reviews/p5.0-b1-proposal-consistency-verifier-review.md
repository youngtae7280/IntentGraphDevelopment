## Scope

P5.0 verifies deterministic consistency between the P4.0 non-applied proposal, proposal validation report, B1 code facts, and B1 overlay mappings.

This slice does not mutate source, apply patches, accept the proposal, use AI judgment as verifier, claim full semantic equivalence, build UI/workbench, or productize the workflow.

## Verifier Boundary

The verifier checks:

- proposal validation report passed
- proposal id matches validation report
- code facts and source digests match proposal baseline
- impacted existing Intent Units exist and are resolved
- planned source changes remain non-applied and within impact scope
- mapping updates reference existing facts and future facts are `future-not-applied`
- required tests, evidence, and authority exist
- source mutation, patch application, AI authority, self-authorization, broad planning, workbench, and productization claims remain false

## Negative Probe Coverage

P5.0 rejects:

- failed proposal validation report
- proposal validation report id mismatch
- stale code facts digest
- missing existing Intent Unit
- missing mapping update
- missing test requirement
- missing evidence requirement
- missing authority requirement
- source mutation claim
- patch application claim
- AI authority claim
