## Scope

P8.61 was intended to verify the P8.60 static graph delta approval workbench in a real browser surface.

The required verification target is higher than structural HTML validation:

- graph is visible.
- graph can be moved.
- graph can zoom in and zoom out.
- fit restores the whole graph.
- graph remains readable after zoom.
- selected graph nodes populate the inspector.
- selected graph edges populate the inspector.
- selected code nodes expose code diffs.
- selected changed nodes expose before/after graph node diffs.
- selected changed edges expose before/after graph edge diffs.
- delta steps highlight affected graph elements.
- the experience is materially close to Graphify-grade inspectability.
